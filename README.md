# ЕС Мениджър — Web версия v2.3.0

Система за управление на етажна собственост — такси, разходи, приходи, отчети и регистър на живущите.

---

## Изисквания

- **Python 3.10 или по-нов** — https://www.python.org/downloads/
  - При инсталация на Windows: отметнете „Add Python to PATH"

---

## Бързо стартиране

### Windows
Кликнете два пъти върху `start.bat`  
Скриптът инсталира зависимостите и стартира сървъра автоматично.

### Linux / macOS
```bash
chmod +x start.sh
./start.sh
```

### Ръчно (всички платформи)
```bash
pip install -r requirements.txt
python app.py
```

След стартиране отворете браузър на **http://localhost:5050** — точният адрес се изписва в прозореца (при зает порт автоматично се избира следващият свободен; фиксиран порт: променлива `ES_PORT`).

---

## Зависимости (`requirements.txt`)

| Пакет       | Версия    | Предназначение              |
|-------------|-----------|-----------------------------|
| Flask       | ≥ 3.0.0   | Уеб сървър и API            |
| ReportLab   | ≥ 4.0.0   | Генериране на PDF отчети    |
| Jinja2      | ≥ 3.1.0   | HTML шаблони                |

---

## Структура на проекта

```
etazna_web/
├── app.py               — Flask сървър и API маршрути
├── requirements.txt     — Python зависимости
├── start.bat            — Стартиращ скрипт за Windows
├── start.sh             — Стартиращ скрипт за Linux/macOS
├── core/
│   ├── accounting.py    — Формули за изчисление на такси
│   ├── apartments.py    — Апартаменти, собственици, живущи
│   ├── finance.py       — Такси, транзакции, категории
│   ├── database.py      — SQLite инициализация и миграции
│   └── audit.py         — Архив на промените
├── reports/
│   └── pdf_generator.py — PDF отчети (ReportLab)
├── templates/
│   └── index.html       — Единствен HTML шаблон (SPA)
├── static/
│   ├── css/app.css      — Стилове (светла/тъмна тема)
│   ├── js/              — JavaScript логика
│   └/  fonts/           — DejaVuSans шрифт за PDF
└── etazna.db            — SQLite база (създава се автоматично)
```

---

## Бележки

- Базата данни `etazna.db` се създава автоматично при първо стартиране.
- Генерираните PDF отчети се съхраняват в `reports/generated/`.
- За спиране на сървъра натиснете **Ctrl+C** в терминала.
