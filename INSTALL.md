# ЕС Мениджър — Ръководство за инсталация

Пълно ръководство за първоначална инсталация и стартиране на **ЕС Мениджър v2.5.1** на нов компютър.

---

## 1. Системни изисквания

- **Операционна система:** Windows 10/11, macOS 12+ или Linux (Ubuntu 22.04+)
- **Python:** версия 3.10 или по-нова
- **Свободно място:** ~200 MB
- **Интернет:** нужен само за инсталация на зависимостите
- **Браузър:** Chrome, Edge, Firefox или Safari (актуална версия)

---

## 2. Най-лесният начин: готов `.exe`

Ако имате файла `ES_Menidzhar_v2.5.1.exe`, **пропуснете точки 3 и 4** —
той не се нуждае от Python, от интернет и от инсталация.

1. Копирайте го в собствена папка, напр. `C:\ES_Menidzhar\`
   (не в „Изтегляния“ — до него се създават базата и архивите)
2. Кликнете два пъти върху него
3. При първото стартиране Windows може да покаже „Windows protected your PC“ —
   натиснете **More info** → **Run anyway** (файлът не е цифрово подписан)
4. Отваря се прозорец с адреса и браузърът тръгва автоматично

До `.exe` файла се появяват `etazna.db` (базата), `backups/` и `reports/generated/`.
Преместване на друг компютър = копиране на цялата папка.

---

## 3. Инсталация на Python (само за стартиране от изходния код)

### Windows

1. Отворете https://www.python.org/downloads/
2. Изтеглете последната версия на Python 3.x (препоръчително 3.12+)
3. Стартирайте инсталатора
4. **ВАЖНО:** отметнете **„Add Python to PATH"** на първия екран
5. Натиснете **„Install Now"**
6. След края натиснете **„Close"**

**Проверка:** отворете Command Prompt (`Win+R` → `cmd` → Enter) и напишете:
```
python --version
```
Трябва да видите напр. `Python 3.12.2`.

### macOS

```bash
brew install python@3.12
```
(ако нямате Homebrew: https://brew.sh)

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3 python3-pip
```

---

## 4. Разархивиране на проекта

1. Разархивирайте `ES_Menidzhar.zip` в удобна папка, напр.:
   - Windows: `C:\ES_Menidzhar\`
   - macOS/Linux: `~/ES_Menidzhar/`
2. Отворете папката — трябва да видите `app.py`, `start.bat`, `start.sh`, `requirements.txt`, `README.md` и директории `core/`, `static/`, `templates/`, `reports/`.

> **Съвет:** не местете файлове вътре в папката. Структурата е важна за правилната работа.

---

## 5. Първо стартиране

### Windows (препоръчително)

1. Влезте в папката на проекта
2. Кликнете два пъти върху **`start.bat`**
3. При първото стартиране ще се инсталират зависимостите (Flask, ReportLab, Jinja2) — отнема 1–2 минути
4. Прозорецът остава отворен и показва:
   ```
   * ЕС Мениджър: http://localhost:5050
   ```
5. Отворете браузъра и въведете адреса от прозореца: **http://localhost:5050**
   (браузърът обикновено се отваря автоматично)

### macOS / Linux

Отворете терминал в папката на проекта и изпълнете:
```bash
chmod +x start.sh
./start.sh
```

### Ръчно стартиране (ако скриптите не работят)

```bash
pip install -r requirements.txt
python app.py
```

---

## 6. Спиране на сървъра

- В прозореца на терминала натиснете **`Ctrl + C`**
- Затваряне на прозореца също спира сървъра

---

## 7. База данни

- При първо стартиране се създава файл **`etazna.db`** в папката на проекта — това е базата с всички данни (апартаменти, такси, транзакции).
- **Архивиране:** периодично копирайте `etazna.db` на друго устройство или USB.
- За пренос на данни към друг компютър: копирайте само `etazna.db` в папката на новата инсталация.

---

## 8. PDF отчети

- Генерираните отчети се записват в `reports/generated/`
- Файловете се именуват автоматично по дата и тип на отчета
- Може да ги изтривате ръчно без риск за базата

## 9. Често срещани проблеми

### „Python not found" / „python не е разпознат като вътрешна команда"
➜ Python не е добавен в PATH. Преинсталирайте с отметка **„Add Python to PATH"**.

### „pip install" грешка / липса на интернет
➜ Проверете връзката. При фирмена мрежа може да е нужен прокси:
```
pip install -r requirements.txt --proxy http://user:pass@proxy:port
```

### Портът е зает
➜ Програмата ползва порт 5050 и автоматично избира следващия свободен,
ако той е зает. Реалният адрес се изписва в прозореца при стартиране.
Фиксиран порт може да се зададе с променливата на средата `ES_PORT`:
```
set ES_PORT=8080      (Windows, преди python app.py)
ES_PORT=8080 ./start.sh   (Linux/macOS)
```

### „Windows protected your PC“ при старт на `.exe`
➜ Файлът не е цифрово подписан. **More info** → **Run anyway**.

### Браузърът не се отваря автоматично
➜ Нормално. Копирайте ръчно адреса от прозореца (напр. http://localhost:5050) в адресната лента.

### Грешка при PDF отчет: „Font not found"
➜ Проверете дали папката `static/fonts/` съдържа `DejaVuSans.ttf`. Ако не — преразархивирайте проекта.

### Изгубени данни / повреден `etazna.db`
➜ Възстановете от последното копие. Ако нямате — изтрийте `etazna.db` и стартирайте наново (данните се губят, създава се празна база).

## 10. Създаване на пряк път (Windows)

1. Десен клик върху `.exe` файла (или `start.bat`) → **„Изпрати до"** → **„Работен плот (създай пряк път)"**
2. Преименувайте на „ЕС Мениджър"
3. Може да смените иконата: десен клик → Свойства → Смени икона
